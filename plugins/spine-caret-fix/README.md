# spine-caret-fix

English | [日本語](README.ja.md)

A personal workaround, kept apart from [spine-tweaks](../spine-tweaks). In the
editor of Tern's Spine chat, the caret sinks into the text. This moves it 3 px
down. The 3 px suits the author's font and line height and may be wrong for
yours.

```sh
tern plugin link plugins/spine-caret-fix
```

Remove it once Tern draws the caret in the right place.
